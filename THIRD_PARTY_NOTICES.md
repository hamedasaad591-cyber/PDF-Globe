# Third-party libraries and services

PDF Globe loads the following browser libraries from public CDNs. Verify the current version and license before upgrading or self-hosting them:

- **pdf-lib 1.17.1** — MIT License
- **PDF.js 3.11.174** — Apache License 2.0
- **JSZip 3.10.1** — MIT License
- **Tesseract.js 5.0.5** — Apache License 2.0
- **DM Sans / IBM Plex Sans Arabic** — font licenses are provided by their respective upstream font projects (OFL)

The server dependencies and external translation provider have their own licenses and terms. Review those terms before commercial use. CDN endpoints and third-party provider policies can change independently of this project.
