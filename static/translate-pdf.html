Translate PDF documents

Extract selectable text from a PDF, use OCR in the browser for image-only pages, translate the extracted text and download the translated text as a Word document.

Use this free tool ↗Free to use within current service limits. Some operations depend on your device or provider quotas.
Page language:العربية

How to use it

Choose a PDF and select the source and target languages.
Agree to send extracted text to the configured translation provider.
Translate, review the output, and download the DOCX file.

How this tool works

PDF Globe currently uses Cloudflare Workers AI as its primary translation provider when configured. Translation is subject to the provider’s free daily allocation, supported language pairs and request limits. The translated DOCX is primarily a text document; the original page design, tables, columns and images are not recreated. Machine translation can make mistakes in names, numbers and specialized terminology.

No account is required to start using the tool.

Frequently asked questions

Does translation preserve the original PDF layout?

No. The current translation flow extracts text and exports the translated text to DOCX; it does not reproduce the original page design.

Is translation unlimited and error-free?

No. The provider has usage quotas and machine translation can make mistakes. Review important names, numbers and legal or technical content.
