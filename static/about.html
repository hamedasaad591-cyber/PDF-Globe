من نحن | About PDF Globe

PDF Globe مشروع أدوات عبر الإنترنت يهدف إلى جعل مهام ملفات PDF والمستندات وتجهيز ملفات الطباعة أسهل وأوضح، من خلال أدوات عملية يمكن استخدامها مباشرة من المتصفح دون إنشاء حساب.

PDF Globe is an independent online tools project focused on making everyday PDF, document and print-preparation tasks easier. Visitors can use the available tools directly in a browser without creating an account.

ماذا يقدم الموقع؟

يجمع الموقع أدوات لتنظيم ملفات PDF وتحويلها وتعديلها، إلى جانب أدوات مساعدة في تجهيز الصور للطباعة. تشمل الوظائف المتاحة دمج الملفات وتقسيم الصفحات وضغط PDF وتحويل المستندات والتعرّف الضوئي على النصوص وترجمة النصوص المستخرجة.

أدوات PDF

دمج وتقسيم وتدوير وترتيب الصفحات، وإضافة العلامات المائية وأرقام الصفحات والتوقيعات.

التحويل والمستندات

تحويل PDF إلى Word وWord إلى PDF، وتحويل الصور إلى PDF أو صفحات PDF إلى صور.

صفّها

ترتيب الصور والتوزيعات والملصقات على ورق A4 أو A3 بأبعاد محددة وتصديرها في ملف PDF.

OCR والترجمة

استخراج النص من بعض الملفات الممسوحة وترجمة النصوص مع ضرورة مراجعة النتيجة.

What the site offers

The site brings together tools for organising, converting and editing PDF files, alongside utilities for preparing images for print. Available functions include merging files, extracting pages, compressing PDFs, document conversion, OCR and translation of extracted text.

PDF tools

Merge, split, rotate and reorder pages; add watermarks, page numbers and signatures.

Document conversion

Convert PDF to Word, Word to PDF, images to PDF, and PDF pages to images.

Saffha

Arrange labels, handouts and images on A4 or A3 sheets using exact dimensions, then export a PDF.

OCR and translation

Extract text from supported scanned files and translate extracted text. Results should be reviewed.

كيف نتعامل مع الملفات؟

بعض الأدوات تنفّذ المعالجة داخل متصفح المستخدم، بينما تحتاج عمليات أخرى إلى إرسال الملف عبر HTTPS إلى واجهة الخادم لتنفيذ التحويل. أداة صفّها تعالج الصور محلياً داخل المتصفح ولا تحتاج إلى رفعها إلى خادم الموقع لإنشاء ملف PDF. تختلف طريقة المعالجة بحسب الأداة؛ لذلك ننصح بمراجعة سياسة الخصوصية قبل استخدام أدوات الخادم أو الترجمة.

النتائج الآلية قد تحتاج إلى مراجعة، خاصة عند التعامل مع الجداول أو النصوص العربية أو الأرقام أو المستندات ذات التنسيق المعقد. الموقع ليس خدمة تخزين دائم أو نسخ احتياطي.

How files are processed

Some tools run directly in the visitor's browser. Other operations transmit a file over HTTPS to the service API for processing. Saffha arranges images locally in the browser and does not need to upload them to the site server to create a PDF. Processing differs by tool, so please read the Privacy Policy before using server-based conversion or translation.

Automated results may need review, especially for tables, Arabic text, numbers and complex layouts. PDF Globe is not a permanent file-storage or backup service.

التواصل والملاحظات

Feedback and support

We welcome user feedback, bug reports and suggestions. When reporting an issue, include the tool name, page URL, device and browser, and the steps that caused the problem. Do not email passwords or sensitive documents.
