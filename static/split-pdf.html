Split PDF and extract pages

Extract selected pages from a PDF or create a smaller PDF from page ranges. Enter page numbers such as 1-3,5,8-10 and download the pages you need.

Use this free tool ↗Free to use within current service limits. Some operations depend on your device or provider quotas.
Page language:العربية

How to use it

Choose one PDF file.
Enter page numbers or ranges, for example 1-3,5.
Run the tool and download the extracted PDF.

How this tool works

Page extraction runs in the browser on your device. The tool validates the page numbers against the document and creates a new PDF containing the selected pages. File size and speed depend on your device and the source document.

No account is required to start using the tool.

Frequently asked questions

Can I extract non-consecutive pages?

Yes. Enter comma-separated page numbers and ranges, such as 1,3,5-7.

Does splitting change the original file?

No. The tool creates a new PDF and leaves your original file unchanged.
