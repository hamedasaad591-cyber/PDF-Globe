Frequently asked questions

Will every table convert perfectly?

No converter can guarantee that for every PDF. Table structure varies, so review the extracted columns and values in Excel.

Does it work with scanned PDFs?

Image-only pages need OCR first so the words can be extracted.

Where does text go if no table is detected?

Selectable text from pages without detected tables is placed in a separate worksheet named Text by page.
