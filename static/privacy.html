English

This notice explains how PDF Globe (“PDF Globe”, “we”, “us”) handles information when you visit pdf-globe.pages.dev and use its PDF and document tools. The service currently does not require an account.

1. How file processing works

Browser-based tools. Tools such as merge, split/extract pages, rotate, delete or reorder pages, watermarks, page numbers, signatures, images-to-PDF, PDF-to-images, and OCR are designed to process the selected content in your browser. The file is not intentionally uploaded to the PDF Globe API for these browser-based operations. OCR software and language data may be downloaded from a third-party content delivery network; the OCR recognition itself runs in the browser.

Server-based tools. Some operations need the PDF Globe API hosted by Render. These currently include PDF compression, PDF-to-Word conversion, Word-to-PDF conversion, PDF repair, and PDF password protection/unlocking. When you choose one of these tools, the selected file is transmitted over HTTPS to the API so the requested operation can be performed.

Translation. Text is extracted or recognised in the browser and sent to the PDF Globe API. The API sends the text to the translation provider configured at the time of the request. The current primary configuration is Cloudflare Workers AI. Depending on service configuration or availability, LibreTranslate or the MyMemory public translation API may be used instead. The original PDF is not intentionally sent to the translation provider by this text-translation workflow; extracted text is sent. The translated text is then sent to the PDF Globe API to generate a downloadable DOCX file.

2. Temporary files and retention

For server-based operations, the application uses request-scoped temporary working folders and is designed to remove uploaded working files and generated outputs when the request finishes. The service does not provide a permanent document library or user file account. This application-level cleanup does not control infrastructure logs, security records, backups, crash diagnostics, or records retained by hosting and third-party providers under their own policies. Unexpected interruption of a server process may also affect normal cleanup.

If you email us, we receive the email address and message content that you choose to send. We retain support correspondence for as long as reasonably needed to respond, keep a record of the communication, and meet applicable obligations.

3. Service providers and external resources

  • Cloudflare Pages: delivers the static website and may process ordinary connection and security metadata.
  • Render: hosts the PDF Globe API and may process request, network, operational, and security metadata. Files submitted for server-based tools pass through this API.
  • Cloudflare Workers AI: receives extracted text when it is the configured translation provider.
  • Other translation providers: LibreTranslate or MyMemory may receive translation text if configured or used as a fallback.
  • Libraries, fonts, and OCR data: the website loads some software libraries, fonts, or language data from third-party delivery services, including Google Fonts, unpkg, cdnjs, and jsDelivr. Those services receive standard request information when your browser retrieves their resources.

These providers operate under their own terms and privacy notices. Please review, where relevant: Cloudflare Privacy Policy, Render Privacy Policy, and Google Privacy Policy. The provider used for translation can change if the service configuration changes.

4. Technical information, cookies, and analytics

Like most websites, the hosting and security providers may receive technical information such as IP address, browser and device details, request time, requested URL, referring page, and error/security events. This information may be used to deliver the site, prevent abuse, troubleshoot errors, and protect the service.

The current website application does not require registration and its application code does not intentionally set first-party login or advertising cookies, or store user profiles in browser storage. The current site code does not intentionally include third-party advertising pixels or an advertising network. Hosting or security providers may still use their own technical mechanisms under their policies. This notice will be updated if analytics, advertising, or other tracking technologies are added.

5. Your choices and responsibilities

  • Choose a browser-based tool when you prefer local processing and the tool supports it.
  • Do not upload documents unless you have the right to use and process them.
  • Avoid submitting highly sensitive documents, including identity, medical, financial, legal, or confidential business records, unless you have reviewed the processing described here and accept the relevant provider arrangements.
  • Keep your own original copies. Do not treat the service as a backup or permanent storage location.

6. Security and international processing

The site uses HTTPS for connections to its public website and API. No internet transmission or storage method can be guaranteed to be completely secure. Cloud hosting and translation providers may process information in countries other than the country where you are located, subject to their own arrangements and applicable laws.

1. كيف تتم معالجة الملفات؟

الأدوات التي تعمل داخل المتصفح: صُممت أدوات مثل دمج الملفات، وتقسيم الصفحات واستخراجها، والتدوير والحذف وإعادة الترتيب، والعلامة المائية، وترقيم الصفحات، والتوقيع، وتحويل الصور إلى PDF، وتحويل صفحات PDF إلى صور، والتعرّف الضوئي على الحروف (OCR) لمعالجة المحتوى داخل متصفحك. لا يُرسل الملف عمداً إلى واجهة PDF Globe الخلفية عند استخدام هذه الأدوات المحلية. قد ينزّل المتصفح مكتبات البرنامج أو ملفات اللغات الخاصة بالتعرّف الضوئي من شبكات توصيل محتوى خارجية، بينما تتم عملية التعرّف نفسها داخل المتصفح.

الأدوات التي تحتاج إلى الخادم: بعض العمليات تتطلب واجهة PDF Globe المستضافة لدى Render، ومنها حالياً ضغط PDF، وتحويل PDF إلى Word، وتحويل Word إلى PDF، ومحاولة إصلاح PDF، وحماية PDF بكلمة مرور أو إزالة الحماية عند معرفة كلمة المرور. عند اختيار إحدى هذه الأدوات، يُرسل الملف المحدد عبر HTTPS إلى واجهة الموقع لتنفيذ العملية المطلوبة.

الترجمة: يُستخرج النص أو يُتعرّف عليه داخل المتصفح، ثم يُرسل النص إلى واجهة PDF Globe. ترسل الواجهة النص إلى مزود الترجمة المهيأ وقت الطلب. الإعداد الأساسي الحالي هو Cloudflare Workers AI، وقد يُستخدم LibreTranslate أو MyMemory كبديل بحسب إعداد الخدمة أو توفر المزود. في مسار ترجمة النصوص، لا يُرسل ملف PDF الأصلي عمداً إلى مزود الترجمة؛ بل يُرسل النص المستخرج. بعد الترجمة يُرسل النص المترجم إلى واجهة PDF Globe لإنشاء ملف Word قابل للتنزيل.
